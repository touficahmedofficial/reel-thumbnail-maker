# Reel Thumbnail Maker

Cover generator for my e-commerce CRO reel series. It's a single HTML file: the fonts and my default photo are built in, so it works offline.

**Live:** https://touficahmedofficial.github.io/reel-thumbnail-maker/

## Use it

1. Open the live link above, or open `index.html` in Chrome.
2. Change the **Episode #** and the **Headline**. Put a `|` in the headline to split it onto two lines, for example `FIX YOUR | PRODUCT PAGE`.
3. Optionally change the series line, italic line, sticker, bottom line, accent colour or photo. A transparent PNG looks best for the photo.
4. Click **Download 9:16 cover** for the reel cover and **Download 4:5 grid** for the profile grid.

The page remembers your last settings in the browser. **Reset to Episode 01** restores the original design.

## Fonts

- Anton: badge, headline, sticker
- Montserrat ExtraBold: bottom line
- Instrument Serif Italic: italic line
- Geist Mono: series line

All are open-source fonts (SIL Open Font License) and are embedded in the file.
